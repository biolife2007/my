﻿Кришка з нержавіючої сталі для перегінних кубів від MagnumStill®


Купольна (сферична) кришка виготовлена з харчової нержавіючої сталі марки AISI304. Товщина ~ 1,2мм

По діаметру підходить для таких перегінних кубів:

Діаметр ~ 330мм - для кубів 14л, 21л, 25л від MagnumStill®

Діаметр ~ 380мм - для кубів 33л, 43л, 40л від MagnumStill®

Діаметр ~ 430мм - для кубів 60л від MagnumStill®

Діаметр ~ 480мм - для кубів 85л, 125л від MagnumStill®


Обирайте потрібний діаметр та розмір клампу на кришці в опціях товару.
